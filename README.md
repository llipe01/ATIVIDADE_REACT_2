# 🎬 MovieCity — Landing Page

O **MovieCity** é uma landing page desenvolvida como atividade prática de React. O projeto apresenta uma interface moderna para exibição de filmes, com cards ilustrativos, menu de navegação e layout responsivo para diferentes tamanhos de tela.

## 🚀 Tecnologias utilizadas

- **React** — criação de componentes e organização da interface.
- **JavaScript** — lógica e interatividade.
- **HTML5** — estrutura da página.
- **CSS3** — estilização, animações e responsividade.
- **Vite** — ferramenta de desenvolvimento e build.

## ✨ Funcionalidades

- Exibição de filmes em cards com imagens.
- Menu de navegação com as opções Filmes, Categoria, Sobre e Contato.
- Menu hambúrguer para dispositivos móveis.
- Botão de Login.
- Efeitos visuais ao passar o mouse sobre os cards.
- Layout responsivo para computadores, tablets e celulares.

## 💻 Como executar o projeto

**1. Clone o repositório**

```bash
git clone URL_DO_SEU_REPOSITORIO
```

**2. Entre na pasta do projeto**

```bash
cd 01_landinpage
```

**3. Instale as dependências**

```bash
npm install
```

**4. Inicie o servidor de desenvolvimento**

```bash
npm run dev
```

**5. Acesse o endereço** exibido no terminal, geralmente `http://localhost:5173`.

## 📚 Objetivo do projeto

Praticar os fundamentos do React, a criação de componentes reutilizáveis, a estilização com CSS e o desenvolvimento de interfaces responsivas.
